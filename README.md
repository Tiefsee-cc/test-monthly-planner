# 测试月度取号规划

双击 `index.html` 可在本地使用。也可在解压目录运行 `python3 -m http.server 8080 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8080/`。同一个入口和浏览器会保留各自的本地数据。导出最新整包需要使用 HTTP 入口。

- 月历中选择日期，直接填写事项说明进行排期，也可从已有事项中选用。
- 点击「排队取号」，填写取号人和事项说明。页面从当天起安排最近没有排期和有效取号的周一至周五，并显示取号回执。
- GitHub Pages 版使用托管数据库保存共享取号记录。从本地打开时使用当前浏览器的数据。
